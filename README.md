# Mboalove-
Site de rencontre camerounais – MboaLove ❤️
MboaLove est un projet de site de rencontre destiné principalement aux Camerounais et à la diaspora africaine.
L’objectif est de permettre aux célibataires de faire des rencontres sérieuses, de discuter et éventuellement de construire une relation amoureuse.
